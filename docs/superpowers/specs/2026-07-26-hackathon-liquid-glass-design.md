# Liquid Glass для карточек «Хакатоны и хобби»

## Цель

Усилить существующие полупрозрачные карточки карусели гибридным эффектом liquid glass: мягким преломлением фона в Chromium и визуально близким CSS fallback в остальных браузерах.

## Основание решения

Статья kube.io описывает физически мотивированное преломление через SVG displacement map и specular highlight, но отмечает, что SVG-фильтры в `backdrop-filter` работают только в Chromium. Библиотека `@ybouane/liquidglass` реализует более точный WebGL-вариант, но требует растеризации DOM, отдельных canvas и динамической перерисовки изменяемого контента. Для семи движущихся карточек поверх 3D-модели выбран более лёгкий CSS + SVG подход без новой зависимости.

Источники:

- https://kube.io/blog/liquid-glass-css-svg/
- https://github.com/ybouane/liquidglass

## SVG-преломление

Внутри `HackathonOrbitCarousel` рендерится один скрытый SVG с фильтром `#hackathon-liquid-glass`.

Фильтр содержит:

- `feTurbulence` с низкой частотой для плавной карты искажения;
- `feColorMatrix`, уменьшающий резкость шума;
- `feDisplacementMap` с небольшим scale, чтобы изгиб был заметен на краях, но не выглядел желеобразным.

В Chromium фильтр применяется только к backdrop карточки. Контент кнопки — текст, индексы и белая графика — остаётся резким и не проходит через displacement.

## CSS fallback

Базовый вид работает без SVG-фильтра:

- `backdrop-filter: blur(18px) saturate(1.25) brightness(1.04)`;
- более прозрачная бело-розовая заливка;
- внутренний светлый кант;
- слабая голубая засветка слева и розовая справа для хроматической аберрации;
- specular-блик через псевдоэлемент;
- мягкая внутренняя тень, создающая глубину выпуклой линзы.

Активная карточка получает более яркий кант и чуть более прозрачный центр. Тёмная тема использует меньшую белую заливку и более заметную розовую кромку.

## Совместимость и производительность

- В Chromium desktop включается `backdrop-filter: url(#hackathon-liquid-glass)` в блоке `@supports`.
- В Safari и Firefox используется только CSS fallback.
- На экранах до `600px` SVG displacement отключается; сохраняется blur и световые кромки.
- Новые npm-зависимости, WebGL canvas и постоянный JavaScript render loop не добавляются.
- Размеры, трансформации, opacity орбиты, автоперелистывание, клик и свайп не меняются.
- `prefers-reduced-motion` не требует отдельного поведения: liquid glass не анимируется.

## Доступность

Скрытый SVG имеет `aria-hidden="true"`, нулевой размер и не перехватывает события. Контраст текста поддерживается существующим белым цветом и text-shadow.

## Проверка

- На странице существует один SVG-фильтр с ожидаемым id.
- Фильтр содержит turbulence, color matrix и displacement map.
- Рендерятся прежние семь карточек.
- CSS содержит базовый fallback, Chromium enhancement и мобильное отключение SVG-displacement.
- Не добавлены WebGL, canvas или новая зависимость.
- Все тесты и production-сборка проходят.
