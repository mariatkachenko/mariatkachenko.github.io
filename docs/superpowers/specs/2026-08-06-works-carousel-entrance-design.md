# Входная анимация карусели «Работы»

## Цель

При каждом открытии страницы «Работы» пять видимых карточек сначала находятся плотной стопкой около центра, затем быстро расходятся в существующую конечную раскладку. После завершения входа карусель работает ровно так же, как сейчас.

## Поведение

- Анимация запускается при монтировании `WorksCardCarousel`.
- Длительность — около 600 мс, easing пружинный, но без сильного отскока.
- Центральные карточки начинают движение сразу, крайние получают небольшую последовательную задержку, создавая раскрытие веером.
- На десктопе начальная стопка компактна по горизонтали; карточки сохраняют небольшие разнонаправленные повороты, чтобы не сливаться.
- На мобильном начальная стопка компактна по вертикали и раскрывается в существующую вертикальную композицию.
- Конечные координаты, размеры, порядок слоёв, оттенение и число видимых карточек не меняются.
- Во время входа карусель не реагирует на drag и wheel, чтобы пользовательское движение не конфликтовало с анимацией. После завершения управление включается автоматически.
- Повторного автоматического проигрывания при обычном drag нет; анимация запускается только при новом открытии страницы.
- При `prefers-reduced-motion: reduce` карточки сразу оказываются в конечном положении.

## Реализация

- Компонент хранит короткое состояние входа `isEntering` и снимает его после окончания CSS-анимации/таймера с безопасной очисткой.
- На контейнер добавляется модификатор входного состояния, а каждой карточке передаётся индекс задержки через CSS-переменную.
- CSS переопределяет только transform/transition во входном состоянии; существующие вычисления позиции остаются источником конечной раскладки.
- Обработчики pointer и wheel игнорируют события, пока `isEntering` активно.

## Проверка

- Тест компонента подтверждает наличие начального класса, задержек карточек и снятие класса после таймера.
- Тесты проверяют блокировку drag/wheel во время входа.
- CSS-тест подтверждает отдельные desktop/mobile начальные положения и отключение анимации для reduced motion.
- После реализации запускаются полный набор тестов и production-сборка.
