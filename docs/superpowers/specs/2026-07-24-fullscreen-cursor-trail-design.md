# Полноэкранный пиксельный след курсора

## Цель

Розовый пиксельный след появляется при движении указателя в любой части экрана, а не только в правой половине.

## Поведение

- Частицы создаются для любой горизонтальной координаты указателя в пределах окна.
- Цвет, форма, плотность, размер, движение и скорость затухания частиц остаются прежними.
- Переход между портретом слева и 3D-моделью справа не меняется.
- Canvas следа остаётся некликабельным и не мешает интерфейсу.

## Реализация

Функция `shouldEmitShimmer` в `src/maria/ShimmerTrail.tsx` больше не сравнивает координату с серединой viewport и возвращает `true` для позиции в любой части экрана. Обработчик `pointermove` продолжает использовать эту функцию, поэтому остальная логика частиц не меняется.

## Проверка

Тест подтверждает генерацию следа для координат в левой и правой половинах. Полный набор тестов и production-сборка должны завершаться успешно.
