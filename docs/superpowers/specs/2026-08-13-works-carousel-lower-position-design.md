# Works carousel lower position

## Goal

Move the `/works` carousel slightly lower without changing the rest of the scene.

## Position

- Desktop carousel top changes from `13vh` to `16vh`.
- Mobile carousel top changes from `32vh` to `34vh`.

## Constraints

- Keep the hand position unchanged.
- Keep card sizes, spacing, layering, drag, wheel, autoplay, and project animations unchanged.
- Do not change the home or About pages.

## Verification

- Desktop and mobile CSS use the approved top positions.
- Existing tests, TypeScript, and production build pass.
