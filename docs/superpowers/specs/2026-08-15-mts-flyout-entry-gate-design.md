# MTS flyout: запуск после входной сцены

## Цель

Устранить прерывания перехода с главной на `/works`, не меняя вид и поведение руки, карусели или самого flyout.

## Решение

- `WorksCardCarousel` получает optional callback `onEntryComplete`.
- Существующий таймер `WORKS_ENTRY_DURATION_MS = 600` одновременно снимает `isEntering` и один раз вызывает callback.
- `WorksPage` начинает с `flyoutVisible = false`.
- После `onEntryComplete` overlay показывается, только если MTS Pay всё ещё является центральной карточкой.
- После первого входа существующая логика перелистывания остаётся прежней: уход скрывает overlay, повторный вход MTS запускает новый activation без дополнительной задержки.

## Запреты

- Не менять CSS и keyframes.
- Не менять View Transition/router.
- Не менять геометрию, autoplay, wheel/drag или длительность входа.
- Не менять главную и страницу «Обо мне».

## Тесты

- Карусель вызывает `onEntryComplete` ровно один раз после 600 мс и не раньше.
- На `/works` overlay отсутствует в первом кадре и появляется после 600 мс.
- Существующие тесты жестов и анимаций остаются зелёными.
- Полный suite и production build проходят.

## Полный откат только этой команды

1. Удалить prop `onEntryComplete` и его вызов из `WorksCardCarousel`.
2. Удалить передачу callback из `WorksPage`.
3. Вернуть начальное значение `flyoutVisible` с `false` на `true`.
4. Удалить два добавленных ожидания тайминга из тестов.

Экранный overlay из предыдущей команды при таком откате сохраняется без изменений.
