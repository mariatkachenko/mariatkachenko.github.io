# MTS flyout: независимый экранный слой

## Цель

Сохранить текущий визуальный вылет логотипа Figma и бабочки, но исключить потерю качества при любом способе попадания на MTS-карточку.

## Архитектура

- Flyout-изображения удаляются из `ConceptProject`, чтобы они больше не наследовали `translate3d`, `rotateY` и `scale` карточки.
- Новый компонент `MtsFlyoutOverlay` рендерится внутри `WorksPage` как сосед карусели, а не её потомок.
- Overlay имеет `position: fixed`, занимает viewport, не принимает события указателя и располагается выше карусели, но ниже presentation modal и fixed chrome.
- `WorksPage` получает индекс центральной карточки через существующий `onCenteredIndexChange` и увеличивает числовой `activation` при каждом новом входе MTS Pay в центр.
- Новый экземпляр/ключ анимации запускает overlay заново при каждом возвращении к MTS Pay.

## Визуальное соответствие

- Используются те же исходные PNG без конвертации и уменьшения.
- Сохраняются текущие длительности, easing, blur, opacity, повороты, масштаб и холодная тень бабочки.
- Стартовые позиции переводятся из координат карточки в координаты viewport так, чтобы исходная композиция визуально совпадала на desktop и mobile.
- Сам flyout масштабируется только собственным `transform`; ни один его предок не масштабируется и не поворачивается.

## Запуск

- При первом открытии `/works` overlay запускается для изначально центральной MTS-карточки.
- При перелистывании overlay запускается, когда MTS становится центральной карточкой.
- Уход с MTS немедленно удаляет overlay, поэтому старая анимация не остаётся на экране.
- Повторное возвращение создаёт новый цикл анимации.
- При `prefers-reduced-motion` overlay скрыт.

## Слои и безопасность

- Overlay не меняет DOM и CSS остальных карточек.
- Presentation modal остаётся выше overlay.
- Fixed header, back button и controls не меняются.
- Главная и страница «Обо мне» не меняются.

## Обратимость

Изменение изолировано: для полного отката достаточно удалить `MtsFlyoutOverlay`, его CSS/тесты, вернуть два исходных `<img>` в `ConceptProject` и старые два `.is-centered` CSS-триггера. Математика и структура карусели не меняются.

## Проверки

- Компонент overlay содержит ровно два полноразмерных исходных PNG.
- `WorksPage` активирует overlay при MTS и сбрасывает при уходе.
- В `ConceptProject` больше нет вложенных flyout-изображений.
- CSS overlay не имеет трансформируемого родителя и сохраняет существующие keyframes.
- Целевые тесты, полный suite, TypeScript и production build проходят.
