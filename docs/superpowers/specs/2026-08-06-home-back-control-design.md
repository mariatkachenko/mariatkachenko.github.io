# Home Back Control Design

Replace the pill-shaped subpage back control with a transparent handwritten link. The visible Russian label is `На Главную`; English uses `Home`. Both use the existing Comforter font and an inline, decorative curved SVG arrow that inherits the current theme color.

The control stays fixed above page content and outside route animations. It remains available on both Works and About pages, keeps the existing home navigation behavior, and scales down on mobile without changing its composition.
